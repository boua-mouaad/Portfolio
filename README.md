# BouaDev — Software Developer Portfolio

A personal portfolio website showcasing my projects, technical expertise, and software engineering work.

## Tech Stack

* React
* Vite
* Tailwind CSS
* React Router
* JavaScript

## Features

* Responsive design
* Light / Dark mode
* Project portfolio
* Technical expertise section
* Contact / inquiry page
* Resume link
* GitHub and LinkedIn links

## Getting Started

Clone the repository:

```bash
git clone https://github.com/bouafia-mouaad/portfolio.git
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
